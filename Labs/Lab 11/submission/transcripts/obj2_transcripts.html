│ `10.10.0.1` .                                                                │
│                                                                              │
│ 3. **Router1 policy-based routing to Firewall1**: Although Router1 has a     │
│ static default route `ip route 0.0.0.0 0.0.0.0 203.0.113.1`, user VLAN       │
│ traffic is steered differently. A route-map on Router1 directs traffic from  │
│ `10.20.0.0/16` toward `10.10.0.6` (Firewall1) .                              │
│                                                                              │
│ 4. **Firewall1 NAT and forwarding**: Firewall1 applies the `inside →         │
│ outside` policy, performs PAT (Port Address Translation) on the source using │
│ the `USER_VLANS` object (NAT to interface `outside`), and forwards the       │
│ traffic to the ISP via `198.51.100.1` .                                      │
│                                                                              │
│ 5. **Return traffic**: Return traffic follows the reverse path with stateful │
│ inspection performed by Firewall1 .                                          │
