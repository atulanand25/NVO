Answer:
Traffic from VLAN 10 (Finance, 10.20.10.0/24) reaches the internet through the following path [source: network_design_doc.md]:

1. **Client to default gateway**: A client on VLAN 10 sends traffic to its default gateway `10.20.10.1` on Switch1 [source: network_design_doc.md].

2. **Switch1 to Router1**: Switch1 forwards the traffic via an OSPF default route learned from Router1, sending it out interface `Gi1/0/24` to `10.10.0.1` [source: network_design_doc.md].

3. **Router1 policy-based routing to Firewall1**: Although Router1 has a static default route `ip route 0.0.0.0 0.0.0.0 203.0.113.1`, user VLAN traffic is steered differently. A route-map on Router1 directs traffic from `10.20.0.0/16` toward `10.10.0.6` (Firewall1) [source: network_design_doc.md].

4. **Firewall1 NAT and forwarding**: Firewall1 applies the `inside → outside` policy, performs PAT (Port Address Translation) on the source using the `USER_VLANS` object (NAT to interface `outside`), and forwards the traffic to the ISP via `198.51.100.1` [source: network_design_doc.md].

5. **Return traffic**: Return traffic follows the reverse path with stateful inspection performed by Firewall1 [source: network_design_doc.md].
